# BAM v0.1 Architecture — Superseded

This document described the initial BAM asset-register implementation and is retained only as historical context.

The current implementation is documented in [BAM v0.2 Architecture](bam-v0.2.md) and the [BAM Operator Guide](../bam-guide.md).

Key capabilities added after v0.1 include multi-asset SHIT relationships, BAMR requests, waitlists, reservation/checkout separation, direct handoff, Vanguard/default stock custody, policy-driven automation, self-service release, allocation holds, and portable backup/restore.
