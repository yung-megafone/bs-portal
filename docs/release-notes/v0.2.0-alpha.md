# B.S. Portal v0.2.0-alpha — Release Notes

`v0.2.0-alpha` is the **relationships, resource allocation, automation, packaging, and operator-QoL** release.

## SHIT

- Board is default when no saved browser preference exists.
- List/Board and Dense/Compact preferences persist.
- Multiple typed BAM asset links per ticket.
- Existing legacy single-asset relationships migrated non-destructively.
- Asset-link history and BAM backlinks.
- Board queue ordering independent from severity.

## BAM requests / resource allocation

- New `BAMR-YY-HHHHHH` request model.
- Multi-item resource bundles.
- Any / Prefer-with-fallback / Require-exact allocation semantics.
- Date-aware conflicts and queues.
- Deterministic equivalent selection.
- Department-scoped manager authority.

## Checkout/custody

- Reservation separated from physical checkout.
- Checkout due/overdue tracking.
- Returns and direct handoffs.
- Future non-overlapping reservation approval while current user still holds asset.
- Privacy filtering of restricted BAMR identifiers.

## Automation

- Vanguard/configurable default stock custody.
- Auto approval + active-window checkout.
- Waitlist reconciliation.
- Auto promotion/transfer on good release.
- Per-asset auto-allocation switch and allocation hold.
- Self-service release with condition reporting.
- Idempotent `process_bam_automation` command.

## QoL

- Global toast notifications.
- Wider workbench-style BAM/SHIT layouts.
- Search/backlinks improved around linked assets.

## Windows packaged application

- PyInstaller `BS-Portal.exe`.
- Waitress and WhiteNoise.
- Inno Setup single download artifact.
- Private MySQL `BSPortalMySQL` on 127.0.0.1:33069.
- ProgramData persistence and DPAPI-protected runtime secrets.
- first-run admin/restore screen.
- tray controls and maintenance modes.

## Backup/restore

- Portable `.bsbackup` format.
- transaction-consistent MySQL dump.
- optional media tree, enabled by default.
- integrity/version/archive validation.
- pre-restore safety backup and automatic rollback attempt.
- dev → packaged first-run restore path.

## Known alpha limitations

- no comment identifier autolinking;
- no formal ticket-to-ticket dependency model;
- no capability-tag/pool matching;
- no external/realtime notification delivery;
- no always-on BAM scheduler;
- no final production RBAC/MFA/rate limiting;
- no hardened unified audit ledger.
